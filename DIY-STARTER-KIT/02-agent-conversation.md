# 02 · Agent 对话模板

## 第一轮：先规划

```text
我想做一个属于自己的桌宠应用。

它要解决的问题：____
目标用户：____
目标平台：____
桌宠角色：____
第一版最重要的三个功能：____
我已经有的素材或代码：____

请先不要写代码。先向我提最多 5 个关键问题，然后输出：
1. 一页产品需求。
2. 最小可用版本边界。
3. 三个可独立验收的里程碑。
4. 风险和需要我做决定的部分。
```

## 第二轮：实现一个切片

```text
请只实现里程碑 1。

开始前：
- 检查现有项目结构和运行方式。
- 先运行当前测试，记录基线。
- 保留无关功能和我现有的未提交修改。

完成后：
- 运行测试和构建。
- 告诉我改了什么。
- 明确哪些界面或行为需要我亲自验收。
```

## UI 修改模板

```text
当前现象：____
出现条件：____
为什么不符合预期：____
期望结果：____
不能改变的行为：____
参考图或尺寸：____
验收标准：____

请先定位布局责任所在的代码，再做最小范围修改，最后构建验证。
```
