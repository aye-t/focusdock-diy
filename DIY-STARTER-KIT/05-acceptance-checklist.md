# 05 · 验收清单

## 核心功能

- [ ] 首次启动不需要私人配置或作者电脑上的文件。
- [ ] 开始、暂停、继续、完成和重置行为可预测。
- [ ] 重启应用后必要状态可恢复。
- [ ] 计时完成不会生成重复记录。
- [ ] 提醒只在用户允许和配置的条件下出现。

## 桌宠和界面

- [ ] 独立组件不保留合并布局的空背景。
- [ ] 窗口大小与内容匹配，不异常拉长。
- [ ] 角色的头、耳朵、脚、尾巴和阴影不被裁切。
- [ ] 动作切换时角色不会明显忽大忽小。
- [ ] 长任务名、不同字体和深浅色模式下仍可读。
- [ ] 外接显示器拔出后，浮窗不会留在屏幕外。

## 工程质量

- [ ] 新用户可以只按 README 完成首次构建。
- [ ] 自动测试通过。
- [ ] 正式构建成功。
- [ ] 无密钥、本机路径、私人日志或用户数据进入 Git。
- [ ] 已说明支持的平台和不支持的平台。
