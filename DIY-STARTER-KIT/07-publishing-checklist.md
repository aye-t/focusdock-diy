# 07 · 公开发布检查

## 隐私和安全

- [ ] 检查当前文件和完整 Git 历史中的密钥、令牌和私钥。
- [ ] 检查 `/Users/...`、Windows 用户目录和私人云盘路径。
- [ ] 排除 `.env*`、部署 ID、Agent 配置、日志、截图和备份。
- [ ] 不使用 `git add .` 盲目提交混杂工作区。
- [ ] 用一台或一个干净用户环境验证首次启动。

## 权利和说明

- [ ] 包含 LICENSE。
- [ ] 对角色、图标、字体、音频和第三方代码拥有使用权。
- [ ] README 没有暗示不存在的平台兼容性。
- [ ] 如果发布 macOS 二进制，说明签名、公证和架构。
- [ ] 如果发布 Windows 版，在真实 Windows 环境测试安装和卸载。

## 可复现性

- [ ] 从全新 clone 安装依赖。
- [ ] 运行所有测试。
- [ ] 构建生产产物。
- [ ] 检查仓库中没有被意外提交的构建产物。
- [ ] 记录已验证的操作系统、工具链和限制。
