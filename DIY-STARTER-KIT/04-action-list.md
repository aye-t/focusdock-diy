# 04 · 桌宠动作清单

| 状态 | 建议动作 | 产品含义 | 必须于 MVP |
| --- | --- | --- | --- |
| 空闲 | 站立/呼吸 | 没有进行中任务 | 是 |
| 专注 | 奔跑/写字 | 计时进行中 | 是 |
| 暂停 | 思考/疑问 | 等待用户继续 | 是 |
| 休息 | 睡觉/抱枕 | 休息阶段 | 后续 |
| 完成 | 庆祝/举牌 | 正向反馈 | 是 |
| 喝水提醒 | 喝水 | 节律提醒 | 后续 |
| 护眼提醒 | 闭眼/远眺 | 节律提醒 | 后续 |
| 久坐提醒 | 伸懒腰 | 节律提醒 | 后续 |
| 欢迎 | 挥手 | 启动和回归 | 后续 |
| 计划 | 剪贴板/文件夹 | 查看任务 | 后续 |

## 每个动作的生成模板

```text
使用已确认的角色母版，保持脸部、色板、头身比、视角和线宽不变。
动作：______
表情：______
道具：______
角色状态：______
完整身体，脚底基线与母版一致，512×512 透明背景，无文字、无裁切。
```

先完成 MVP 的 3–5 个动作，在真实应用中验证视觉尺寸和切换，再扩展完整动作集。
