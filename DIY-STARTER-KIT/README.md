# DIY Starter Kit

这套模板用来帮你把“我想做一个桌宠”变成可以被 Agent 理解、实现和验收的项目。

## 推荐顺序

1. `01-idea-brief.md`：定义问题，而不是先选技术。
2. `02-agent-conversation.md`：给 Agent 清晰的上下文和验收标准。
3. `03-character-bible.md`：先锁定角色，再生成动作。
4. `04-action-list.md`：管理桌宠动作和产品状态的对应。
5. `05-acceptance-checklist.md`：判断它是否真的可用。
6. `06-debug-feedback.md`：把“它很丑”转成可执行的修改请求。
7. `07-publishing-checklist.md`：防止把隐私、密钥和本地数据公开。

## 不要一次做完所有功能

可以把第一版限制为：

- 一个角色
- 三个动作
- 一个核心任务
- 一种成功反馈
- 一种保存方式

第一版稳定后，再增加提醒、动画、每日计划、跨平台或云同步。
