# 06 · Bug 和 UI 反馈模板

## 反馈公式

```text
当前现象：
触发步骤：
预期行为：
实际行为：
出现频率：
影响范围：
不能被改变的功能：
截图/录屏/错误日志：
验收标准：
```

## 好的 UI 反馈示例

```text
当只开启番茄钟时，图标后面仍然有合并模式的长背景。
我期望单独模式只保留图标、必要的阴影和点击区域。
不能改变当前的计时状态、点击弹窗和右键菜单。
修改后请测试数字、番茄、沙漏和进度环四种样式。
```

## 不足的反馈

```text
它很丑，帮我优化一下。
```

这种说法没有告诉 Agent 丑在哪里、什么不能变，也没有可验收结果。
